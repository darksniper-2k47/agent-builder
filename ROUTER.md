# ROUTER.md — Agent Builder map

| Intent | Read | Skip | Tools | Output |
|---|---|---|---|---|
| Build a new agent | `lessons.md`, `identity.md`, `rules.md`, agent-building brain, real source materials for that job | unrelated existing agent brains | `tools/check_agent_folder.py` after scaffolding | editable build PRD, smallest agent folder, validation report |
| Audit an existing agent | same files plus target router/identity/rules/lessons/reference headings and representative outputs | unrelated project folders | validators and read-only inspection | gap map: present / weak / missing / out of scope |
| Improve an agent after a verdict | target `lessons.md` first, failing output, generating rule/knowledge/tool | unrelated symptoms | smallest relevant validator | system-layer fix plus preserved verdict lesson |
| `pick up` / `hand off` | `shared/pickup-handoff.md`, `state.md` | domain source material until target is known | none | continuity brief or verified state update |

If no route matches, return to `AGENT_ENTRY.md`. Never build an agent from a vague example when the recurring job, real inputs, and success bar are unknown.
