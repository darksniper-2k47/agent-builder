# quality-checks.md — the bar every output passes before "done"

Run these on any brief or deliverable before declaring it finished.

1. **Investigated, not summarized.** Did the strategist ask the questions that change the work, or
   just restate the request?
2. **Lane + real job named.** Is the actual outcome stated, not just the surface task?
3. **Knowledge cited.** Does it name specific course(s) / `_ingest` files, found with
   `find_in_library.py` — not "the content course" in general?
4. **One first step.** Is there a single concrete next action (record / write / open)?
5. **Gaps named honestly.** If an asset is missing (transcript, portfolio piece, WhatsApp number),
   is it called out as step zero — not glossed over?
6. **Voice.** Anti-hype, sentence case, no banned words, no exclamation marks.
7. **Filed right.** Correct slug + path per `naming-conventions.md`.
8. **Local + safe.** No tool reached the network, used a secret, or wrote outside `projects\`.

If any check fails, fix it before moving on. This is the self-correction loop.
