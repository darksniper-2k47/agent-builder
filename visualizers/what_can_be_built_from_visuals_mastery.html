Zero-Token Headless Tool

1. Automated SVG / PIL Visual Generator (`tools/generate_visual.py`)

Instead of manually logging into Canva, we can write a local Python script that programmatically compiles all 18 templates into pixel-perfect SVG and high-res PNG files:

  • Dark Obsidian Mode: Pure `#000000` background, clean white silhouette icons, gold/crimson callouts, bold sans-serif text.
  • Notebook Paper Mode: Lined notebook paper texture background, clean hand-drawn style typography, stark black ink.
  • One-line CLI: python generate_visual.py --template "then_vs_now" --left "Then: Reacting" --right "Now: Choosing Silence" --output out.png
